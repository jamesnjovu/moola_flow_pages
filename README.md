# Moola Flow pages

Public legal pages for the Moola Flow Android and iOS app, served with GitHub Pages.

| Page | URL |
|---|---|
| Home | https://jamesnjovu.github.io/moola_flow_pages/ |
| Privacy policy | https://jamesnjovu.github.io/moola_flow_pages/privacy-policy/ |
| Delete account | https://jamesnjovu.github.io/moola_flow_pages/delete-account/ |

The privacy policy URL goes in Play Console under **Policy and programs > App content > Privacy policy**, and the delete account URL goes in the **Data safety** form.

## Editing

Plain HTML and CSS, no build step. Edit the files, commit and push to `main`; GitHub Pages republishes in a minute or two.

When the app starts collecting new data (a new SDK, permission or field), update the privacy policy, change its effective date, and update the Play Console Data safety form to match.
